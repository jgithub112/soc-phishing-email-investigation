This project documents a hands-on SOC investigation of a suspected phishing email.

The investigation began with a phishing alert triggered by a suspicious sender/Reply-To mismatch and subsequently involved analysis of Base64-encoded email attachments, file signature identification, and extraction of a ZIP archive containing multiple files.

Note: This repository is intended for cybersecurity portfolio and educational purposes. Sensitive or personally identifiable information should be sanitized before publication.
Lab Environment: Investigation performed in an isolated VMware virtual machine using a publicly available lab email artifact.
